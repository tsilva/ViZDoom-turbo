# Surface Theme Grid v1

Generation mode: built-in imagegen

## Prompt

Use case: stylized-concept
Asset type: one production sprite-sheet-style grid containing nine original seamless game textures for a Doom-compatible reinforcement-learning environment.

Primary request: create an exact 3 columns by 3 rows grid of nine equal square texture cells. Columns are fixed in this order: COLUMN 1 = front-facing WALL material, COLUMN 2 = top-down FLOOR material, COLUMN 3 = flat orthographic CEILING material. Rows are three visually coherent environment themes; every wall, floor, and ceiling within one row must share a coordinated material language and palette while remaining clearly distinguishable by surface role.

ROW 1 — Polar Research Bunker: wall is ice-blue insulated metal panels with pale frost at joints; floor is dark navy frozen slate plates with restrained pale cracks; ceiling is gunmetal service-grid panels with small cold-cyan conduit details.
ROW 2 — Desert Solar Shrine: wall is warm ochre sandstone blocks with sparse dark-bronze braces; floor is worn terracotta and muted-gold geometric stone mosaic; ceiling is dark bronze coffer panels with restrained amber-gold inlay.
ROW 3 — Verdant Ruin: wall is gray-green ancient masonry with sparse moss and oxidized copper seams; floor is dark lichen-covered flagstone with muted fern-green flecks; ceiling is a flat root-and-copper lattice over shadowed green stone panels.

Grid composition: exactly nine equal cells, strict straight grid, narrow uniform neutral medium-gray gutters separating cells, no labels, no headers, no captions, no extra panels. Keep all important texture content away from gutters. Every cell is a uniform repeating material with no focal point. Opposite edges within every individual cell should join seamlessly.

Style/medium: crisp low-resolution 1990s first-person-shooter pixel art; hard pixel clusters; limited readable palettes; flat material capture; designed to survive nearest-neighbor downscaling to exactly 64x64 pixels. Consistent pixel scale and rendering treatment across all nine cells.

Lighting: flat neutral material lighting only; no directional cast shadows; no overall gradients; no bright glare.

Constraints: fully opaque; original designs only; each row must read as one coherent matched wall/floor/ceiling set; each row must be clearly different from the other rows; wall cells front-facing and orthographic; floor cells top-down and planar; ceiling cells orthographic and planar.

Avoid: perspective, rooms, corridors, horizon lines, objects, characters, creatures, weapons, holes, stairs, lamps, visible depth, text, numbers, logos, trademarks, watermarks, UI, borders around the outer canvas, recognizable copyrighted designs, or any layout other than the exact 3x3 grid.
